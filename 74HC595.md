Currently the project uses a 74LS373 between the atmega1284p and the z80 databus. This allows the 1284p to present a byte, and the z80 can read it through the 74ls373 and immediately send the 74ls373 outputs tri-state at the end of a memory cycle rather than taking 100ns to go tristate which would happen if the 1284p was directly connected to the bus. 

I want to explore switching the 74ls373 out for a 74hc595. The 1284p would need to use a clocked serial transfer to the 74hc595 to send out one byte, but the 74lhc595 still has tri-state control on its outputs. This would be a lot slower than 74ls373 but would free up a lot of gpio pins. What I want to know is where there is SPI hardware or similar within the 1284p that could be used to clock out a byte relatively quickly or whether it would need to be done in assembly as fast as possible which would still end up slower than if I kept using the 74ls373
